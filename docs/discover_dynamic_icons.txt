DISCOVER SECTIONS — WHERE EACH TILE'S IMAGE COMES FROM
======================================================
Source of truth for the section list:
lib/features/common/Discover/view/discover_screen.dart, `_sections` (line ~110).

RULE
----
If a section's CATEGORY LIST comes from the API, its tile IMAGE comes from the
API too (`image_url` on the category/profession object). If the list is bundled
in the app, the image is bundled with it (assets/discover/, class DiscoverIcons).

No section mixes the two any more. There used to be four "hybrid" sections —
API list, bundled artwork keyed by tagId — and they were the worst of both:
a category the backend added rendered blank until the app shipped an asset for
it, which is exactly what reading the list from the API is supposed to avoid.

Consequence: for the seven sections in §1, NOTHING can be fixed from the app.
The art has to be uploaded backend-side. The per-category mapping below says
which file from assets/discover/ belongs to each, so that upload doesn't have
to be re-derived.

3. THE PLATE RULE  ***read before uploading any of §1***
===============================================================================
Old Discover art was a transparent cut-out, so the tile drew a pale-blue CIRCLE
behind it (#F2F6FF, 14% padding). Every icon in assets/discover/ instead ships
its artwork already on a tinted rounded-square. Put one in the circle and you
get a coloured square floating on a blue disc, disc poking out at the corners.

So the tile asks DiscoverIcons.isSelfContained(path) — a prefix test on
'assets/discover/' — and drops the plate when true. Implemented in:
    DiscoverTilePlate       discover_category_section.dart
    _DiscoverFolderPlate    discover_folder_tile.dart

A URL is never self-contained, so every §1 section still gets the circle. THIS
MATTERS FOR THE UPLOAD — two options, pick one:

  (a) Upload TRANSPARENT CUT-OUTS (strip the tinted square). Everything works
      as-is, and §1 keeps the same circular look it has today.
  (b) Upload the files as delivered, WITH the tinted square, and widen the rule
      so category URLs count as self-contained too. One edit in each of the two
      widgets above. §1 and §2 then look identical.

Do NOT upload the files as delivered without doing (b) — that is the
square-on-circle case.
